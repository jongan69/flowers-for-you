# Flowers for you

A rotating bouquet made of text characters.

Open `index.html` in a browser. Everything runs locally, with no dependencies.

Append `?edit=1` to the website URL to customize the message and copy a gift link.

Browser adaptation of [Alish Sharma’s ASCII Flower Bouquet](https://github.com/alishsharma17/Ascii-Flower-Bouquet-), used under the MIT license. The original license is retained in LICENSE and embedded in the page source.
